# Senin Cargo

**Удобное приложение для покупки товаров из Китая и выгодной доставки в Кыргызстан.** Заказывайте на Taobao, 1688, Alibaba, Poizon, Pinduoduo и других площадках — поиск на русском языке и по фото, оплата в сомах, автоматический выкуп сразу после оплаты, консолидация посылок и отслеживание груза от склада в Китае до пункта выдачи в Кыргызстане.

🌐 Сайт: **[senin.site](https://senin.site)**

### Установка
1. Скачайте APK по ссылке выше.
2. Откройте файл — Android предложит разрешить установку из этого источника, подтвердите.
3. Готово. Обновления ставятся поверх, данные сохраняются.

## Возможности
- 🔍 Поиск миллионов товаров по крупнейшим китайским маркетплейсам — на русском языке и по фото
- 💳 Оплата в сомах — картой или по банковской ссылке
- 🤖 Автоматический выкуп сразу после оплаты
- 📦 Консолидация посылок — несколько заказов в одну экономичную отправку
- 🚚 Отслеживание на каждом этапе: от склада в Китае до пункта выдачи
- 🔔 Push-уведомления о статусе доставки
- 🧾 Полная история заказов, платежей и отправлений
- 🏷️ Раздел с новостями, акциями и специальными предложениями

## Почему Senin Cargo
Одни из самых выгодных тарифов на рынке, оптимизированные сроки доставки, надёжная логистика и полный контроль на каждом этапе пути — от разовой покупки для себя до регулярных оптовых поставок для бизнеса.
