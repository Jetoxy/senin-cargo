# Сенин Карго — Senin Cargo

**Покупки в Китае и доставка в Кыргызстан в одном приложении.** Товары крупнейших китайских площадок и Poizon — прямо в приложении: поиск на русском и по фото, цена сразу в сомах. Заказы с Pinduoduo и других площадок оформляйте на наш склад в Китае — дальше мы доставим посылку до пункта выдачи рядом с вами.

### Сборки для Android

Здесь публикуются официальные сборки, в том числе новые версии до выхода в магазины:

- **[⬇ senin-cargo.apk](https://github.com/Jetoxy/senin-cargo/releases/latest/download/senin-cargo.apk)** — для большинства телефонов
- [senin-cargo-armv7.apk](https://github.com/Jetoxy/senin-cargo/releases/latest/download/senin-cargo-armv7.apk) — для старых 32-битных телефонов

Как установить:
1. Скачайте файл и откройте его — Android попросит разрешить установку из этого источника, подтвердите.
2. Если приложение уже установлено из Google Play, сначала удалите его: сборка отсюда не встанет поверх версии из магазина.
3. Войдите по коду. Избранное, корзина и заказы сохранятся.

## Возможности

- 🛍️ **Товары китайских площадок в приложении** — поиск на русском и по фото, цена сразу в сомах
- 👟 **Poizon — оригинальные бренды**: обувь, одежда, электроника; характеристики и таблица размеров у каждого товара
- 💳 **Оплата в сомах** через приложение вашего банка
- 📦 **Адрес склада в Китае** для заказов с Pinduoduo и других площадок
- 🚚 **Отслеживание посылки** от склада в Китае до пункта выдачи, уведомления о каждом этапе
- 📍 **Пункты выдачи по всему Кыргызстану** — тарифы вашего пункта прямо в приложении
- 🔐 **Вход по коду** из WhatsApp, Telegram или SMS
- 📏 **Таблица размеров** одежды и обуви и инструкция по Pinduoduo на кыргызском языке
- 🧾 **История** заказов, платежей и выданных посылок

## Почему Сенин Карго

Выгодные тарифы, понятные сроки и контроль на каждом этапе пути — от разовой покупки для себя до регулярных поставок для бизнеса.
