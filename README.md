# Senin Cargo

**Заказ и доставка товаров из Китая в Кыргызстан.** Поиск по крупнейшим китайским маркетплейсам (на русском и по фото), оплата в сомах, автоматический выкуп и отслеживание посылки до выдачи в Оше.

🌐 Сайт: **[senin.site](https://senin.site)**

## 📲 Скачать приложение (Android)

**[⬇ Скачать последнюю версию](https://github.com/Jetoxy/senin-cargo/releases/latest/download/senin-cargo.apk)**

Для старых телефонов (до ~2016 г., 32-бит): [senin-cargo-armv7.apk](https://github.com/Jetoxy/senin-cargo/releases/latest/download/senin-cargo-armv7.apk)

### Установка
1. Скачайте APK по ссылке выше.
2. Откройте файл — Android предложит разрешить установку из этого источника, подтвердите.
3. Готово. Обновления ставятся поверх, данные сохраняются.

## Возможности
- 🔍 Поиск миллионов товаров — на русском языке и по фото
- 💳 Оплата в сомах — картой или по ссылке банка
- 🤖 Автоматический выкуп сразу после оплаты
- 📦 Отслеживание: от продавца в Китае до пункта выдачи в Оше
- 🧾 История заказов и платежей
